# Custom ResNet classes

To train recognition for sườn xám, add at least 20 varied images here:

```text
custom_data/
└── Cheongsam/
    ├── cheongsam_001.jpg
    ├── cheongsam_002.jpg
    └── ...
```

Use correctly labelled JPG, JPEG, PNG or WEBP images with different colours,
poses, camera angles and backgrounds. Do not duplicate images across classes.
